Project Description: Developed Intelliscout, a machine-learning-based football scouting and player evaluation system that analyzes player statistics to generate objective player rankings and support scouting decisions. 
CTGAN (Conditional Tabular GAN) was used for synthetic data generation and dataset augmentation.
XGBoost, ANN, and DNN were then used for feature-weight generation, followed by weighted player scoring and position-specific ranking. 
Spectral Clustering grouped players into three performance-based clusters, while PCA reduced the feature dimensions for 2D cluster visualization.
A radar chart module was developed to compare the performance profiles of two or three players across multiple attributes. 
Dynamic Substitution was proposed as a future extension.
